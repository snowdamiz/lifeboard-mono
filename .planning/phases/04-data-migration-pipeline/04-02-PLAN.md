MegaPlanner.Repo is the existing SQLite Ecto repo (already started by Application.ensure_all_started(:mega_planner)).

PRAGMA foreign_keys = OFF must be sent INSIDE Repo.transaction/2 callback — this guarantees same-connection execution. ecto_sqlite3 sets foreign_keys: :on when checking out connections. After the transaction, re-enable with PRAGMA foreign_keys = ON.

Repo.insert_all/3 requires atom keys (not string keys):
```elixir
defp atomize_keys(map), do: Map.new(map, fn {k, v} -> {String.to_existing_atom(k), v} end)
# Note: use String.to_existing_atom/1 not String.to_atom/1 to avoid atom table exhaustion on 48 tables * many columns
# However, column names from JSON may not be existing atoms — use String.to_atom/1 for first-pass safety
# since the number of unique column names is bounded and small
```

Import table helper (for non-special-FK tables):
```elixir
defp import_table(rows, table_name) do
  if rows == [] do
    IO.puts("  #{table_name}: 0 rows (skipped)")
  else
    entries = Enum.map(rows, &atomize_keys/1)
    {count, _} = MegaPlanner.Repo.insert_all(table_name, entries, on_conflict: :nothing)
    IO.puts("  #{table_name}: #{count} rows")
  end
end
```

Tables requiring two-pass handling:
1. tasks (self-referential: parent_task_id -> tasks.id)
2. goal_categories (self-referential: parent_id -> goal_categories.id)
3. purchases + budget_entries (circular: purchases.budget_entry_id <-> budget_entries.purchase_id)

Two-pass pattern for self-referential (tasks, goal_categories):
- Pass 1: insert all rows with the self-ref column set to nil
- Pass 2: UPDATE rows where the original value was non-nil

Two-pass pattern for circular (purchases <-> budget_entries):
- Pass 1: insert purchases with budget_entry_id = nil; insert budget_entries with purchase_id = nil
- Pass 2: UPDATE purchases.budget_entry_id; UPDATE budget_entries.purchase_id

Import order (PRAGMA OFF means order doesn't matter for FK validity, but keep this for clarity):
- First: households, users, tags, units, drivers, stores (leaf dependencies)
- Then: all other non-special tables
- Special last: tasks, goal_categories, purchases+budget_entries (two-pass)

    ```
      MegaPlanner.Repo.query!("PRAGMA foreign_keys = OFF")

      # Standard tables (no two-pass needed)
      import_table(tables["users"], "users")
    ```

    ```
    MegaPlanner.Repo.query!("PRAGMA foreign_keys = ON")
    result = MegaPlanner.Repo.query!("PRAGMA foreign_key_check")
    case result.rows do
      [] ->
        IO.puts("\nPRAGMA foreign_key_check: PASSED — zero violations")
        IO.puts("Import complete.")
      violations ->
        IO.puts("\nPRAGMA foreign_key_check: FAILED — #{length(violations)} violations")
        Enum.each(violations, fn [table, rowid, parent, fkid] ->
          IO.puts("  #{table} rowid=#{rowid} -> #{parent} (fk #{fkid})")
        end)
        raise "Foreign key violations found after import — see above"
    end
    ```

    Create `server/lib/mix/tasks/migrate.verify.ex` with the count comparison implementation.

    Module: `defmodule Mix.Tasks.Migrate.Verify`, `use Mix.Task`, `@shortdoc "Compare record counts between PostgreSQL and SQLite for all tables"`.

    `run/1` function body:
    1. `Application.ensure_all_started(:mega_planner)`
    2. Read `POSTGRES_URL` from environment: `System.get_env("POSTGRES_URL") || raise "POSTGRES_URL is required for verify. Run: fly proxy 5432:5432 -a mega-planner-api-db first, then: POSTGRES_URL=ecto://user:pass@localhost:5432/mega_planner_api mix migrate.verify"`
    3. Parse and start Postgrex (same pattern as export task): `opts = Ecto.Repo.Supervisor.parse_url(database_url) |> Keyword.put(:pool_size, 2) |> Keyword.put(:timeout, 60_000)` then `{:ok, pg} = Postgrex.start_link(opts)`
    4. Get table list from SQLite (excluding schema_migrations): `result = MegaPlanner.Repo.query!("SELECT name FROM sqlite_master WHERE type='table' AND name != 'schema_migrations' ORDER BY name")` then `tables = result.rows |> List.flatten()`
    5. For each table, query count from both databases:
       - PostgreSQL: `Postgrex.query!(pg, ~s(SELECT COUNT(*) FROM "#{table}"), []) |> then(& &1.rows |> hd() |> hd())`
       - SQLite: `MegaPlanner.Repo.query!(~s(SELECT COUNT(*) FROM "#{table}")) |> then(& &1.rows |> hd() |> hd())`
    6. Track discrepancies: if pg_count != sqlite_count, add to discrepancies list and print `"MISMATCH #{table}: pg=#{pg_count} sqlite=#{sqlite_count}"`; otherwise print `"OK #{table}: #{pg_count}"`
    7. Final summary: if discrepancies empty, print `"\nVERIFY: PASSED — all #{length(tables)} tables match"` and exit 0; otherwise print `"\nVERIFY: FAILED — #{length(discrepancies)} tables with mismatches"` and `exit({:shutdown, 1})`

    Important: wrap the per-table queries in a `try/rescue` so that if a table exists in SQLite but not PostgreSQL (or vice versa), it prints a warning rather than crashing. Catch `Postgrex.Error` and `Ecto.QueryError`.
