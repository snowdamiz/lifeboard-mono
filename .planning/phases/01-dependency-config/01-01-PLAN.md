Purpose: Remove the PostgreSQL driver entirely and declare ecto_sqlite3 as the adapter so the Repo module and all downstream config files can reference `Ecto.Adapters.SQLite3`.

Output: Updated mix.exs (no postgrex, ecto_sqlite3 added, ecto_sql bumped), updated repo.ex (SQLite3 adapter), updated config.exs (migration_primary_key for binary_id).
</objective>
