serialize/1 type conversion (Postgrex returns these non-JSON-serializable types):
```elixir
defp serialize(%NaiveDateTime{} = dt), do: NaiveDateTime.to_iso8601(dt)
defp serialize(%DateTime{} = dt), do: DateTime.to_iso8601(dt)
defp serialize(%Decimal{} = d), do: Decimal.to_string(d)
defp serialize(list) when is_list(list), do: Enum.map(list, &serialize/1)
defp serialize(map) when is_map(map), do: Map.new(map, fn {k, v} -> {k, serialize(v)} end)
defp serialize(v), do: v
```

    1. `Application.ensure_all_started(:mega_planner)` — starts the app so Repo and config are available

    4. Parse the URL and start Postgrex: `opts = Ecto.Repo.Supervisor.parse_url(database_url) |> Keyword.put(:pool_size, 2) |> Keyword.put(:timeout, 60_000)` then `{:ok, pg} = Postgrex.start_link(opts)`
